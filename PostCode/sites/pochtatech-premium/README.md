# Почтатех Плюс — демонстрация подписки

Статическая демонстрационная страница в визуальной системе официального сайта
Почтатеха. Название подписки рабочее. Содержание взято из чата «Идеи для подписки»:
кредиты на отправку, шесть возможных дополнительных привилегий и калькулятор.
Демотариф — 299 ₽/месяц и два кредита по 200 ₽. Это условные гипотезы, а не
официальное предложение; дополнительные идеи не объявлены составом демотарифа.
Настоящего подключения, оплаты, регистрации и сбора персональных данных нет.

## Запуск

Из этой папки:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173. Установка зависимостей и сборка не нужны.

## Файлы

- `dist/index.html` — содержание страницы.
- `dist/styles.css` — адаптивная вёрстка и цвета.
- `dist/app.js` — информационное окно и калькулятор для 0, 1 или 2 кредитов.
- `dist/assets` — локальные копии оригинальных логотипа, шрифта и иллюстрации.
- `DESIGN.md` — исследование визуальной системы и источники ресурсов.
- `.openai/hosting.json` — существующий Site и статическая директория `dist`.

Калькулятор предполагает полное использование номинала каждого выбранного
кредита: `количество × 200 − 299`. Проверены результаты −299 / −99 / 101 ₽.

Исходный стиль: https://pochta.tech/. Ресурсы используются для демонстрационного
макета; страница явно обозначена как неофициальный проект хакатона.
