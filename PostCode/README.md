# Почта Премиум · PostCode

Прототип платной подписки Почты России для хакатона, команда из двух человек.
Официальное ТЗ получено 24.11.2026: [требования и готовность](docs/requirements-2026-11-24.md).
Рабочий прототип включает личную подписку, калькулятор, предзапись, управление бонусами, корпоративные роли, счета и отчёт CSV. Цены и платежи демонстрационные.

## Запуск

Из корня репозитория запустите `python run.py` и откройте http://127.0.0.1:4173. В Windows откройте start.cmd двойным щелчком. Он откроет браузер и покажет адрес в консоли. Из «Загрузок» он также ищет проект в Documents/ChatGPT/PostCode текущего пользователя. Для переноса на другой компьютер распакуйте весь архив PostCode-MVP.zip и запустите start.cmd из распакованной папки. Требуется Python 3.10 или новее. Состояние сохраняется между запусками в SQLite.

| Каталог | Назначение |
| --- | --- |
| `sites/pochtatech-premium` | Существующее демо и его дизайн |
| `src/app` | Будущие страницы и транспортные обработчики API |
| `src/components/ui` | Общий интерфейс |
| `src/features/landing` | Ценность, FAQ, CTA |
| `src/features/plans` | Потребительский и корпоративный тарифы |
| `src/features/calculator` | Услуги, выгода и окупаемость |
| `src/features/subscription` | Подключение, статус, пауза, отмена |
| `src/features/benefits` | Активация, лимиты, история |
| `src/features/corporate` | Компания, роли, сотрудники, бюджеты, отчёты |
| `src/features/waitlist` | Предзапись и согласие на обратную связь |
| `src/server/services` | Правила и проверка полномочий |
| `src/server/repositories` | Данные и транзакции |
| `src/server/integrations` | Имитации платежа и каталога тарифов, будущие адаптеры |
| `src/shared` | Общие типы и ошибки без секретов |
| `db` | Будущие миграции и синтетические фикстуры |
| `tests` | Будущие проверки расчётов, лимитов и сценариев |
| `deliverables` | Комплект сдачи и его статус |
| `docs` | Требования, архитектура, экономика, документация |

Работающее приложение использует Python и SQLite. Интерфейс собран в src/app, предметные каталоги src/features оставлены для дальнейшего разделения. Старый лендинг сохранён в sites/pochtatech-premium.

## Проверки и сдача

Проверка сценариев: `python tests/integration/test_local_mvp.py`. Сводка конверсий: `python tools/funnel.py`. Подробный маршрут проверки приведён в технической документации.

GitHub используется для разработки по запросу владельца. Официальная сдача —
только в выданный командный GitLab до 01.12.2026 23:59; часовой пояс уточняется.
Ветки `codex/<задача>`, затем PR/MR. Секреты, реальные контакты, токены и локальные
БД не публиковать. Сценарий видео не заменяет готовую запись.

## Обновлённые сценарии

Корзина услуг, календарные периоды, отзыв заявки, история платежей, запрос возврата, отключение сотрудников, печатные счета и калькулятор экономики доступны в интерфейсе. GET /api/catalog и GET /api/basket предоставляют открытые контракты. Девять проверок запускаются командой python tests/integration/test_local_mvp.py. Сборка переносимого ZIP — python tools/package.py.
