# Подготовка промпта до отправки

Адаптер к установленному [Prompt Optimizer](https://github.com/linshenkx/prompt-optimizer)
v2.16.0. Переводит запрос на английский и удаляет повторы с помощью локальной
Ollama / qwen3:8b. Код приложения хакатона и его зависимости не затрагивает.

## Использование

```powershell
prompt-en "Привет, пожалуйста, сделай страницу подписки с 3 тарифами. Оплату не подключай."
prompt-en --file request.txt
prompt-en --clipboard
codex-en "Сделай страницу подписки, интерфейс оставь на русском."
```

`prompt-en --clipboard`: скопируйте написанный запрос, выполните команду,
вставьте подготовленный текст в чат. На рабочем столе есть ярлык
«Сократить промпт» для того же действия. Буфер не изменяется при ошибке
или если пользователь успел скопировать другой текст во время обработки.

`codex-en`: сначала готовит текст локально, затем запускает интерактивный
Codex в текущей папке с подготовленным запросом. Используется существующий
вход Codex в ChatGPT; API-ключ OpenAI для подготовки текста не нужен.

**Поле ввода текущего приложения автоматически не переписывается.**
Его `UserPromptSubmit` хук может добавить контекст, но не заменить исходный
запрос: https://learn.chatgpt.com/docs/hooks#userpromptsubmit
Вызов оптимизатора после отправки текста в модель не экономит исходный запрос.

## Настройки и ограничения

- Настройки: `%USERPROFILE%\.config\prompt-en\config.json`.
- Переопределение пути: переменная `PROMPT_EN_CONFIG`.
- Разрешён только Ollama на `http://127.0.0.1:11434`; облачные запросы блокируются.
- Используется отдельная Node 24.22.1; системная Node не заменяется.
- Код, пути, цитаты и числа маскируются до перевода и восстанавливаются.
- Потерянные/повторённые литералы и ответы не на английском отклоняются.
- Смысловой эквивалентности всех требований локальная проверка не доказывает:
  подготовленный текст стоит просматривать, особенно для неоднозначного запроса.
- Дополнительный ответ модели оплачивается вычислениями компьютера; снижение
  расхода всей квоты ChatGPT не измерялось и не гарантируется.
- Промпты и результаты адаптер не записывает на диск. Сама Ollama работает
  согласно своей конфигурации; содержимое буфера обрабатывается только по команде.

## Проверка адаптера

```powershell
node --test tools/prompt-en/engine.test.mjs
```

Для проверки модели используйте синтетический запрос через `prompt-en`.
Тест не должен автоматически запускать рабочую задачу Codex или читать буфер.
