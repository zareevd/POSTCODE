## Инструменты экономии контекста

Проверено 2026-11-19 по первичным источникам. RTK OSS 1.2.0 и Context Mode 2.2.1
установлены и настроены для Codex; подробности — в [tooling.md](tooling.md).

| Инструмент | Что сокращает | Применимость |
| --- | --- | --- |
| [RTK](https://github.com/rtk-ai/rtk) | Вывод команд до передачи агенту: Git, тесты, сборка и журналы | Установлен; проверены фильтр Git и хук Codex |
| [Context Mode](https://github.com/mksglu/context-mode) | Большие результаты инструментов хранит локально в SQLite, возвращает выбранные фрагменты | Установлен; doctor проверил MCP, хуки и skills |
| [Prompt Optimizer](https://github.com/linshenkx/prompt-optimizer) | Локальная подготовка английского запроса без повторов | Собран v2.16.0; адаптер prompt-en использует существующую Ollama/qwen3:8b |

- RTK документирует Windows и Codex CLI. Автоматический хук Codex описан для
  поддерживаемых `Bash`-команд. Проверены `rtk git status`, `rtk rewrite` и
  обработка синтетического хука с документированным `permission_mode`.
  Автоматическая обработка всех команд текущего чата не проверена. Источник:
  https://www.rtk-ai.app/docs/getting-started/supported-agents/#codex-cli
- У RTK есть Apache-2.0 редакция `rtk-oss` с фильтрами команд и полная редакция
  с дополнительным движком. Для базовой фильтрации не нужна модель-суммаризатор;
  делегирование внешней модели через отдельные pipelines не входит в этот выбор.
  Редакции и условия: https://www.rtk-ai.app/docs/resources/editions/
- Context Mode заявляет бесплатную локальную работу, офлайн-индексацию и поиск,
  поддержку Codex, Windows и лицензию ELv2. Отдельный платный Gateway не требуется
  для локального плагина. Нужны Node >= 24.15.0 и Git for Windows; shell-команды
  на Windows выполняются в Git Bash. Источник:
  https://github.com/mksglu/context-mode#install
- Prompt Optimizer v2.16.0 требует Node ^24.22.1. Для него отдельно установлены
  Node 24.22.1 и pnpm 10.6.1; системная Node 26.13.1 сохранена.
- Проценты авторских бенчмарков относятся к отфильтрованному выводу/байтам, а
  не к гарантированному уменьшению всей квоты подписки. Локального замера нет.
- Начать с одного инструмента и сравнить несколько реальных команд; отдельно
  проверить сохранность ошибок и возможность получить полный вывод.

### Подготовка промпта до отправки

- Официальный `UserPromptSubmit` Codex добавляет developer-контекст либо
  блокирует отправку; замена исходного сообщения этим механизмом не описана:
  https://learn.chatgpt.com/docs/hooks#userpromptsubmit
- Поэтому адаптер подготавливает текст через локальную модель до ручной
  вставки в приложение (`prompt-en --clipboard`) либо до запуска Codex CLI
  (`codex-en`). Поле ввода текущего приложения не перехватывается.
- Примеры сохранения чисел, путей, подписей кнопок и запретов проверены на
  синтетических запросах. Пять автоматических проверок защищают литералы и
  отклоняют некорректные результаты. Смысловая эквивалентность не гарантируется.
- Перевод на английский сам по себе не доказывает снижение расхода подписки.
  Локальная подготовка не использует платный OpenAI API.
