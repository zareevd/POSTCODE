# Почта Премиум · локальный MVP

Из корня проекта запустите `python run.py` (проверялось на Python 3.13). На Windows можно открыть start.cmd. Перейдите на http://127.0.0.1:4173. Для другого порта используйте `python run.py --port 4174`. Ctrl+C останавливает сервер. Установка пакетов и внешние сервисы не требуются.

## Проверка за три минуты

1. На главной оформите предзапись тестового профиля. Согласие на обратную связь выбирается отдельно. Откройте калькулятор, выберите две посылки по 400 ₽. Скидка 40 ₽, после платы остаётся 11 ₽.
2. В кабинете выберите отказ в оплате, затем успешную оплату. Примените бонус к посылке. В истории появится 20 ₽, останется 30 ₽ доступной скидки. Проверьте паузу, возобновление и отмену.
3. В разделе для бизнеса подключите демо-компанию, добавьте сотрудника с лимитом скидки 15 ₽ и откройте его профиль. Две посылки дадут 12 и 3 ₽ скидки. Вернитесь в роль бухгалтера, проверьте оплаченный счёт и скачайте CSV. Личный и корпоративный балансы независимы.
4. Перезагрузите страницу. Состояние сохраняется по cookie браузера. Отдельный профиль браузера создаёт независимый набор данных. При повторном запуске используйте тот же адрес.

## Устройство

`run.py` обслуживает HTML-формы, HTTP API и CSV. HTML формируется в `src/app/views.py`, адаптивные стили в `src/app/style.css`. Бизнес-правила находятся в `src/server/services/premium.py`, синтетические цены и имитация платежа в `src/server/integrations/demo.py`, SQLite в `src/server/repositories/store.py`. Используются стандартная библиотека Python (PSF), встроенная SQLite (public domain) и локальные файлы Golos из прежнего демо. Приложение запускается без npm, сборки и CDN.

База создаётся в db/premium.sqlite3. Путь можно переопределить через POSTCODE_DB. Таблица profiles хранит демо-компанию, участников, подписку и журнал операций в рамках сессии. Таблица events хранит события без контактов. Транзакция BEGIN IMMEDIATE сериализует изменения. У отправленных форм есть ключ повтора и CSRF-токен. Повтор с тем же ключом возвращает прежний результат.

## Расчёт и период

Личный тариф 2900 копеек за календарный месяц, 5% и предел 5000 копеек. Бизнес 29900 копеек, 3% и предел 50000 копеек. Для одной операции скидка равна целой части цены в копейках × ставка / 100. Для выбранного количества применяется потолок тарифа. При фактической операции учитываются также оставшиеся общий и личный лимиты. Чистая выгода равна скидке минус плата. Для окупаемости делим плату на скидку за операцию с округлением вверх. При нулевой скидке окупаемости нет.

Каталог содержит посылку за 400 ₽, письмо за 120 ₽, упаковку за 80 ₽ и исключённую международную посылку за 1200 ₽. Это синтетические цены уже после обычных скидок. Расчёт за полный период доступен как JSON: `GET /api/quote?plan=personal&service=parcel&quantity=2`. Тарифы personal/business, услуги parcel/letter/box/international, количество 0–1000. Поля total, discount, net в копейках, threshold в операциях или null. Некорректный ввод получает HTTP 400.

Конец периода вычисляется через один календарный месяц от даты подключения. Если дня в следующем месяце нет, берётся последний день месяца. Верхняя граница исключительная. Используется локальная дата сервера. Запланированную паузу или отмену можно отозвать до этой даты. Когда период закончился, пользователь снова явно подтверждает тестовый платёж. Фонового списания, банковских карт, возврата средств и реального счёта-фактуры в этом прототипе нет.

## Аналитика и проверки

`python tools/funnel.py` показывает число уникальных сессий и долю от всех посетивших главную по каждому действию. Это охват этапов, допускающий разные пути посетителя. Все действия в локальной базе демонстрационные. Эксперимент и финансовые предположения описаны в [бизнес-обосновании](business-case.md).

`python tests/integration/test_local_mvp.py` прогоняет личный и корпоративный пути через HTTP-обработчик с временной SQLite. Запросы и ответы проходят через потоки байтов, что позволяет проверять формы, cookies, перенаправления и CSV без сетевого доступа. Проверяются также параллельный повтор формы и переход на границе периода.

Демо предназначено для одного локального компьютера. Переключение ролей открыто для показа сценария, реальные сотрудники не авторизуются. Счета фиксируют только плату за подписку. Для промышленного запуска нужны идентификация, договорные тарифы, настоящий биллинг, правила обработки данных и инфраструктура заказчика. Совместимость со всеми четырьмя браузерами ещё предстоит проверить.


## Расширения рабочего приложения

Калькулятор /calculator принимает корзину всех четырёх услуг. /api/basket?plan=personal&parcel=2&box=5 возвращает строки корзины и общий результат с единым потолком скидки. /api/catalog публикует версии тарифов, цены в копейках и признаки применимости. /health возвращает JSON status=ok.

Предзапись принимает тестовый email @example.invalid, хранит версию и дату согласия. Отзыв удаляет контакт из профиля. Исторические события воронки сохраняются без email. На /analytics видны события своего профиля, общий отчёт остаётся в tools/funnel.py.

Личный кабинет хранит успешные и неуспешные имитации платежа. Запрос на возврат отключает продление и получает статус pending. Решение по реальному возврату в этом приложении не выполняется.

Администратор меняет название компании, бюджеты и отключает сотрудников. Удаление сотрудника сохраняет его историю. Счета доступны на /invoice?id=1, печатаются через Ctrl+P, видны администратору и бухгалтеру. После окончания тарифа доступны прошлые счета и история. Администратор явно оплачивает следующий период.

Экран /economics пересчитывает MRR, contribution LTV, LTV/CAC и срок окупаемости CAC при изменении допущений. Условия демонстрации доступны на /terms. Никакие изменения в калькуляторе экономики не меняют реальный тариф текущего демо.

Девять автоматических сценариев проверяют HTTP-формы и SQLite без сетевого подключения. Покрыты CSRF, ограничения профиля сотрудника, отказ платежа, параллельный повтор, лимиты, отзыв заявки, возврат, корзина, счета, истечение периода, сохранение истории и календарные границы. Визуальный прогон четырёх браузеров ещё не выполнен.
