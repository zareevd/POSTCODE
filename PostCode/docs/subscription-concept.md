# Концепт из чата «Идеи для подписки»

Источник: чат [«Идеи для подписки»](https://chatgpt.com/c/6afef40f-c438-83eb-861d-cf0f43ec8a0a),
прочитан 2026-11-19. Пользователь попросил перенести содержание на существующий
демонстрационный сайт. В исходном чате это предложения ассистента, а не
утверждённые условия Почтатеха. Официальное ТЗ по-прежнему не получено.

## Аудитория и основная идея

Начальная аудитория — люди, отправляющие несколько посылок в месяц, в том числе
продавцы вещей на площадках объявлений. Основа демонстрационного предложения —
кредиты, уменьшающие стоимость отправки.

Для тех, кто в основном получает заказы, предложено исследовать пакет хранения
и курьерского забора возвратов. Это направление развития, не второй действующий
тариф на текущей странице.

## Семь гипотез

| Идея | Содержание из обсуждения | Как показана на сайте |
| --- | --- | --- |
| Кредиты на отправку | 1–2 кредита в месяц уменьшают стоимость посылки; в числовом примере — два по 200 ₽ | Главная идея и карточка демотарифа |
| Курьерский забор | Один забор с адреса в месяц для отправки или возврата | Возможная привилегия |
| Упаковка | Стандартная коробка при отправке по подписке | Возможная привилегия |
| Дополнительное хранение | Дополнительные дни для подходящих типов отправлений | Возможная привилегия, без выдуманного количества дней |
| Возврат через приложение | Заказ → QR-код → отделение или забор; только для поддерживающих магазинов | Возможная привилегия с оговоркой |
| Семейный баланс | Общий пакет отправок и видимый остаток | Возможная привилегия |
| Пакет для продавцов | Предсказуемая цена, печать этикеток списком, единая история | Возможная привилегия |

## Демонстрационные числа

- Подписка: 299 ₽ в месяц.
- Кредиты: два в месяц, номинал каждого 200 ₽.
- Максимум льгот в примере: 400 ₽.
- При полном использовании двух кредитов: 400 − 299 = 101 ₽ за месяц.
- Формула калькулятора: `использованные_кредиты × 200 − 299`, выбор 0, 1 или 2.
- Для 0 / 1 / 2 кредитов результаты: −299 / −99 / 101 ₽.

Это упрощённый иллюстративный расчёт, не тарифный калькулятор Почты России и не
подтверждённая экономика продукта. Он предполагает полное применение номинала
каждого кредита. Наличные выплаты и настоящий платёж не реализованы.

## Границы изменения

Добавлены тексты, карточки идей и локальный калькулятор. Бизнес-сценарий из чата
«подключить подписку → оформить отправление → применить кредит → увидеть остаток»
остаётся кандидатом для следующего этапа после ТЗ; сервер и платёж не добавлялись.
