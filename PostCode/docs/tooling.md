## Подготовка текста

Инструкция: [tools/prompt-en/README.md](../tools/prompt-en/README.md).

```powershell
prompt-en --clipboard
prompt-en --file request.txt
codex-en "Сделай страницу подписки, оплату не подключай."
```

На рабочем столе установлен ярлык «Сократить промпт»: сначала скопировать
написанный запрос, запустить ярлык, затем вставить результат в чат. Сам ярлык
сообщений не отправляет. Поле ввода приложения автоматически не меняется.

- Локальный движок: `%LOCALAPPDATA%\CodexTools\prompt-optimizer\v2.16.0`.
- Отдельная среда Node/pnpm: `%LOCALAPPDATA%\CodexTools\prompt-runtime`.
- Копия адаптера: `%LOCALAPPDATA%\CodexTools\prompt-en`.
- Настройки: `%USERPROFILE%\.config\prompt-en\config.json`.
- Команды: `%USERPROFILE%\.local\bin\prompt-en.cmd` и `codex-en.cmd`.
- Модель: существующая `qwen3:8b`, Ollama `127.0.0.1:11434`.
- Не подключались облачный Gateway, платные API и дополнительные модели.
- Исходники адаптера находятся в репозитории; после изменения нужно обновить
  установленную копию двух `.mjs` в каталоге выше.

## Резервные копии

- До установки: `%LOCALAPPDATA%\CodexTools\backups\20261119-152340`.

конфигурацию, если после установки в неё уже вносились другие изменения.
