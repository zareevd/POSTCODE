## Подготовка и критерий готовности

Запустить локально одной командой, сбросить демоданные, подготовить два синтетических профиля. Убрать реальные контакты, уведомления и токены из кадра. Записать 1080p с разборчивым интерфейсом и голосом; проверить начало, середину, конец и итоговый размер. В титре указать демонстрационность платежа и тарифов. Сохранить итоговый MP4 в командный GitLab; одного сценария недостаточно для сдачи задачи «Видеопрезентация».

Для записи запустите python run.py и пройдите маршрут из technical-documentation.md. В прототипе период равен 30 дням, профиль компании демонстрационный.
