# Проверки перед сдачей

Статус: план для будущего приложения. Сейчас исполняемых тестов нет.
Команды добавить в README после выбора стека.

## Ключевые сценарии

- Подключение подписки сохраняется после обновления страницы.
- Повторное подключение обрабатывается согласно контракту.
- Использование привилегии корректно меняет результат и доступный лимит.
- Повторный запрос не списывает привилегию второй раз.
- Исчерпанный лимит и неактивная подписка обрабатываются корректно.
- Отмена и завершение срока соответствуют условиям продукта.
- Ошибки внешней системы и отсутствие данных видимы пользователю.
- Демонстрационные данные можно восстановить перед повторным показом.

## Техническая готовность

- Установка из lock-файла в чистом окружении.
- Проверка типов и production-сборка.
- Основной сценарий по развёрнутой ссылке.
- Удобство основного сценария на мобильном экране.
- Секреты и локальные БД отсутствуют в коммите.

Автоматизировать критичные бизнес-правила и основной сквозной сценарий.
Не писать тесты, которые проверяют только наличие папок или повторяют код.
