# Рабочая версия · 24.11.2026

Доработаны корзина с общим лимитом, календарные месяцы, личные платежи, отзыв предзаписи, запрос возврата, управление компанией, отключение сотрудников, печатные счета, сохранение истории после истечения тарифа, JSON-каталог и экран экономики.

Проверены девять сценариев через HTTP-обработчик и SQLite. Пакет собирается tools/package.py и проверяется после чистой распаковки. Существующие изменения сохранены. Запись в .git ограничена окружением, новая ветка не создана.

Дальше — визуальная проверка в Chrome, Edge, Firefox и Яндекс Браузере, запись видео. Ограничения — локальный демо-профиль с переключением ролей, тестовые контакты, симуляция оплаты и ручное продление. Внешние интеграции и реальные договорённости с партнёрами отсутствуют.

## Исправление запуска из «Загрузок»

Сообщение Windows показало, что прежний start.cmd искал run.py рядом со скачанным файлом. Обновлённый launcher находит проект по соседству или в Documents/ChatGPT/PostCode пользователя и просит системный браузер открыть фактический адрес после привязки порта. Проверен запуск отдельной копии start.cmd из временной папки. Из чистой распаковки deliverables/PostCode-MVP.zip прошли три интеграционных теста. Доступ браузера пользователя к странице отдельно не подтверждён.
